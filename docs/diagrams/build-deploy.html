Build and deploy

atto1 build and deploy

A merge to main runs the check and deploys nothing. The owner's Approve fast-forwards deploy; the Worker and its migrations ship from there.

Sources: README.md (Private values, Deploy, Releases), docs/deploy-branch.md, .github/workflows/deploy.yml, release.yml, scripts/render-wrangler.ts. The deploy job runs on GitHub-hosted ubuntu-latest; its Cloudflare credentials and the Worker values come from Secrets Manager through sm-action, scoped to the migrate and deploy steps. A migration is not undone by a revert: write a reversing migration.
