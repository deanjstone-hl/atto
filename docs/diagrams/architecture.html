Architecture

atto1 architecture

One Cloudflare Worker with static assets, behind Access, over D1. The BYD collector posts readings through its own service token.

Sources: README.md (Status, Stack, BYD collector), docs/byd-collector.md, worker/index.ts, docs/decisions/adr-005-d1-worker-behind-access.md. The Worker verifies Access tokens on every request, serves the built app and exposes one ingest path for the collector token. Private ids and the Access team domain live in Secrets Manager and are not drawn.
